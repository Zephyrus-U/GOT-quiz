# GOT Quiz

A polished, dependency-free Game of Thrones / ASOIAF universe quiz built as a single HTML page.

## Features

- 10 lore questions with score tracking
- Animated green correct and red wrong-answer feedback
- Gradient progress bar
- Emoji-based results screen with restart flow
- Responsive narrow-column layout
- Ivory and red visual theme with `prefers-color-scheme` support

## Run locally

Open [`index.html`](index.html) directly in a browser. No server, build step, or dependencies are required.

## Project structure

All application markup, styling, quiz data, and behavior live in `index.html`.
